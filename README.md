# AgentCraft

![Version](https://img.shields.io/badge/version-0.1.0-blue.svg)
![Angular](https://img.shields.io/badge/Angular-22-dd0031.svg)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4-38bdf8.svg)

Visual builder and configurator for AI coding agents rules and context files (`.cursorrules`, `copilot-instructions.md`, `CLAUDE.md`, etc.).

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build

# Run unit tests
npm test -- --watch=false
```

---

## 🛠️ Tech Stack

- **Framework:** Angular 22 (Standalone Components, Signals)
- **Styling:** Tailwind CSS v4 (Dark-mode first, responsive)
- **Language:** TypeScript (Strict mode)
- **Testing:** Vitest
